ДОШКА РОЗСЛІДУВАННЯ — пакет для GitHub Pages

1. Створіть репозиторій на GitHub.
2. Завантажте ВСІ файли та папки з цього архіву в корінь репозиторію (не сам ZIP).
3. Відкрийте Settings → Pages.
4. У Build and deployment виберіть Deploy from a branch.
5. Branch: main, Folder: /(root), натисніть Save.
6. Зачекайте на публікацію; адресу сайт покаже в Settings → Pages.

Важливо: GitHub Pages робить сайт загальнодоступним в інтернеті. Не публікуйте його, якщо вміст має залишатися приватним.
