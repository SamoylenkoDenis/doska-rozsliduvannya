ГОТОВА СТРУКТУРА ДЛЯ GITHUB PAGES

1. Клонуйте репозиторій https://github.com/SamoylenkoDenis/doska-rozsliduvannya через GitHub Desktop.
2. Скопіюйте ВСЕ з цієї папки в локальну папку репозиторію (разом із прихованою папкою .github).
3. У GitHub Desktop натисніть Commit to main, потім Push origin.
4. У GitHub відкрийте Settings → Pages → Build and deployment → Source → GitHub Actions.
5. Відкрийте Actions і дочекайтеся успішного Publish site to GitHub Pages.

У репозиторії мають бути index.html, assets/, .nojekyll і .github/workflows/pages.yml у корені/за вказаним шляхом.
